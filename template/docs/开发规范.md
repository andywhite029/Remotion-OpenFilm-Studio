# 开发规范

[项目首页](../README.md) · [制作指南](制作指南.md) · [素材与渲染](素材与渲染.md)

## 1. 先守住五条边界

1. **画面是 `frame` 的纯函数**：同一帧必须得到同一画面，支持乱序、并行渲染。
2. **一个时间轴**：[timeline.ts](../src/timeline.ts) 提供 `VIDEO`、`SEG`、`TIMELINE_END`；组件不复制帧号。
3. **一个主题**：[theme.ts](../src/theme.ts) 提供 `C` 与排版、布局、动效令牌；组件不写裸色值。
4. **内容与引擎分开**：日常改片只动 [sequences/](../src/sequences/)、时间轴和主题；共享引擎只收通用能力。
5. **交付前 `npm run check` 全绿**：不能靠放宽校验器或降低 `CONTRAST_PAIRS.min` 过关。

禁止用 `Math.random()`、`Date`、`Date.now()`、`useState` 驱动动画，以及跨帧可变状态。
禁止用 `setTimeout`、`setInterval`、`requestAnimationFrame` 计时；动画时间只取自当前帧。

## 2. 改动落点

| 位置 | 职责与改动边界 |
| --- | --- |
| [timeline.ts](../src/timeline.ts) | 格式、节拍窗口、总时长；改节奏只改这一处 |
| [theme.ts](../src/theme.ts) | 语义颜色、字体、间距、安全区、圆角、阴影、动效时长 |
| [sequences/](../src/sequences/) | 文案、素材、数据、beat 组装；项目内容放这里 |
| [lib/format.ts](../src/lib/format.ts) | 纯数值工具、缓动、插值、格式化 |
| [lib/motion.ts](../src/lib/motion.ts) | beat 窗口到进度、入退场、错峰 |
| [components/](../src/components/) | 共享文字、面板、动效、卡片、图表、版式原语 |
| [three/](../src/three/) | 共享 3D 舞台与帧驱动对象；修改前确认可跨项目复用 |
| [compositions.ts](../src/compositions.ts) | 合成注册表：id、组件、时长、fps、宽高 |
| [Root.tsx](../src/Root.tsx) / [index.ts](../src/index.ts) | 注册表映射为 `Composition`，再 `registerRoot`；新增合成无需修改 |
| [remotion.config.ts](../remotion.config.ts) | 入口、资源根、编码与浏览器等全局渲染配置 |
| [public/](../public/) / [assets/](../src/assets/) | 前者用 `staticFile()`，后者用 `import` 进入打包器 |
| [scripts/](../scripts/) / [tools/](../tools/) | `.mjs` 工具链 / Node 直接运行的 `.ts` 校验器 |

渲染数据流：时间轴与主题 → 纯函数工具 → 共享组件 → 内容组装 → 合成注册 → Remotion。
**改内容，不顺手改引擎**；确需调整共享层时，检查其他合成是否回归。

## 3. 时间轴与多合成

- `SEG` 的窗口为 `[from, to)`，按故事顺序排列，不重叠，衔接时不留空洞。
- beat id 使用 kebab-case；`TIMELINE_END` 为最大 `to`，`VIDEO.DURATION` 必须覆盖它。
- 入场组件的 `start` 是绝对合成帧，从 `SEG[id].from` 派生，不在组件中写死。
- 进度使用 `revealIn`、`revealOut`、`beatProgress`、`beatEnvelope`；不要重复手算窗口比例。
- 同组错峰用 `stagger(i, step = 4, max = 24)`，避免元素过多拖长入场。
- 一个仓库只保留一套 `SEG` 和一套活动 `C`：**一条主线片 + 同结构变体**。
- 同节拍、同画幅、同配色，仅换文案、数据、语言或 logo：新增合成并复用组件。
- 长短版可按最长版排节拍，短版只取前几拍；校验器不会验证短版是否真的截取正确。
- 不同节拍结构、画幅或品牌：派生目录；深色版走分支或派生，不并存第二套配色变量。

### 新增与删除

```bash
npm run new -- ProductTour
npm run new -- DataStory --duration 600 --fps 30
```

脚手架新建内容组件并登记到 [compositions.ts](../src/compositions.ts)，默认格式取自时间轴。
手动新增也只需：在 [sequences/](../src/sequences/) 新建默认导出的 React 组件，再添加 import 与注册项。
以下两个标记必须原样保留；新增项插在对应标记之前，删除合成也不能删它们：

```ts
// @new-composition-import
// @new-composition
```

- 要接入主片：把内容挂到 [Main.tsx](../src/sequences/Main.tsx) 的相应 `BeatLayer`，在唯一时间轴分配窗口。
- 删除合成：同步删除内容组件、注册 import 和注册项；仅在不再使用 3D 时删除共享 3D 内容。
- 删除 [Main.tsx](../src/sequences/Main.tsx) 后，渲染与静帧命令必须显式指定合成 id，不能依赖默认 `Main`。
- 删除后运行 `npm run check`，清理悬空引用并确认时长契约。

## 4. 组件怎么用

优先组合现有构件；内容专用组装留在 [sequences/](../src/sequences/)，不要复制一套共享原语。

| 构件 | 常用方式 |
| --- | --- |
| [Frame / Safe / Center / Footer](../src/components/Frame.tsx) | 全幅底色 / 内容安全区 / 居中 / 页脚装订线 |
| [FadeIn / SlideIn / ScaleIn](../src/components/Motion.tsx) | `start` + `duration` 驱动入场；方向、距离或缩放按需配置 |
| [Typewriter / DrawLine](../src/components/Motion.tsx) | 帧推导字符数 / 线条绘制，不使用定时器 |
| [Typography](../src/components/Typography.tsx) | `Display/H1/H2/H3/Lead/Body/Small/Micro/Mono/Kicker`；`color` 传令牌 |
| [Panel / Rule / Chip / Dot](../src/components/Surfaces.tsx) | 卡片、分隔线、状态胶囊、状态点；状态点不能单独表意 |
| [Stat / ProgressBar](../src/components/Surfaces.tsx) | 标签读数 / `value` 为 0–1 的进度；动画改值，不另改宽度 |
| [TitleCard / BeatHeader / EndCard / LowerThird](../src/components/Cards.tsx) | 开场、拍页头、收尾、帧级悬浮标注；按窗口传 `start/end` |
| [LineChart / BarRow](../src/components/Chart.tsx) | SVG 折线 / 横向柱；用 `reveal` 控制绘制进度 |

## 5. 视觉令牌速查

所有取值以 [theme.ts](../src/theme.ts) 为准；改规范就改令牌，不在组件里写例外。
颜色、字号、间距和阴影不得硬编码；禁止直接写十六进制或 `rgba()`。
状态浅底使用 `withAlpha(C.positive, 0.1)` 等从令牌派生，随主题自动变化。

| 令牌组 | 用途 |
| --- | --- |
| `canvas / surface / surfaceAlt / surfaceSunken` | 舞台底板 / 主页面 / 次级块 / 凹陷区 |
| `border / borderSubtle` | 可见轮廓 / 发丝分隔线 |
| `text / textSecondary / textTertiary` | 主文案 / 说明标签 / 微文案；微文案不豁免对比度 |
| `accent / accentBright / accentInk` | 文本与细线 / 品牌填充渐变大字 / 强调色阶终点 |
| `accentSubtle / accentBorder / onAccent` | 洗染 / 强调描边 / 实心强调底上的文字 |
| `positive / warning / negative` | 正向 / 警告 / 错误，不以颜色作为唯一信息 |
| `shadow1 / shadow2 / shadow3` | 静置卡片 / 抬起面板与 HUD / 悬浮素材 |
| `glass / scrim` | 素材上磨砂胶囊 / 字幕后压暗遮罩 |

- 浅色深度靠细线与阴影，不靠发光；禁止 `text-shadow` 和大半径彩色发光。
- 阴影只选三档，不加码模糊半径或不透明度；静置卡片优先 `Panel shadow={1}`。
- 全片统一冷中性色，不在个别 beat 混入暖灰面板。
- 深色不是反相：仅将活动 `C` 切换为 `PALETTES.dark`，角色含义保持不变。

### 排版、间距与动效

| 令牌 | 当前档位与约束 |
| --- | --- |
| `TYPE` | display 96 / h1 68 / h2 48 / h3 34 / lead 28 / body 22 / small 17 / micro 13 |
| `LEADING` | tight 1.06 / snug 1.2 / normal 1.5；优先由文字组件配好 |
| `TRACK` | display -0.02em / heading -0.01em / normal 0 / caps +0.12em |
| `SPACE` | xs 8 / sm 12 / md 20 / lg 32 / xl 52 / xxl 80；只用这六档间距 |
| `SAFE` | 上下 72、左右 96；正文在 `Safe` 内，满幅出血必须有意为之 |
| `RADIUS` | card 20 / panel 14 / media 16 / chip 999 |
| `MOTION` | fast 12 帧 / base 18 帧 / slow 30 帧：微转场 / 默认入场 / 大位移 |

- 字号走文字组件；`Display` 大字全片只开一次；数字、时间码用 `Mono`，避免宽度跳动。
- 默认缓动 `easeOutCubic`，对称过渡用 `easeInOutCubic`；不要逐组件另造动效语法。
- 动内容块与标题线，不动背景洗染和作为装订线的页头、页脚。
- 切点用交叉溶解，沿用 [Main.tsx](../src/sequences/Main.tsx) 的 `BeatLayer`；首拍不半透明开场，末拍淡出。

### 对比度与素材承载

- 正文、微文案及文本档强调色至少 **4.5:1**；主文字与 `accentInk` 的已登记配对至少 **7:1**。
- `accent` 用于文字、图标、细线；`accentBright` 只用于品牌填充、渐变、大字等，不能代替正文强调色。
- 实心 `accent` 底上的文字用 `onAccent`；不要靠肉眼猜可读性。
- 新增文字色、改变表面或增加实际使用配对时，更新 `CONTRAST_PAIRS`，覆盖真实前景与背景。
- [checkContrast.ts](../tools/checkContrast.ts) 对浅、深两套色板分别校验，当前 13 对 × 2；透明色先与背景合成再测。
- 不降低门槛、不放宽检查器；使用令牌也不代表任意前景背景组合都已被校验。
- 深色素材用 `Panel`、细边与 `shadow2/3` 承载；不对素材本体加滤镜、混合模式或背景模糊。
- 深色媒体岛以 `canvas` 留出安全边距，说明用 `glass` 胶囊；仅胶囊允许背景模糊。
- 素材本身除边框、圆角外不加装饰；更多操作见 [素材与渲染](素材与渲染.md)。

## 6. 工具约束与验收

- [timeline.ts](../src/timeline.ts) 与 [theme.ts](../src/theme.ts) 必须零 import，只放可独立加载的数据、算术与纯函数。
- [tools/](../tools/) 由 Node 原生类型剥离直接运行：不用 `enum`、`namespace`、构造器参数属性。
- 工具引用源码带 `.ts` 后缀；源码内部 import 由打包器处理，不带后缀；项目使用 ESM，不用 `require`。
- 资源引用：`staticFile('media/x.png')` 相对 [public/](../public/)，不带资源根前缀，不手写根相对 URL。
- 中文路径用 Node `path` API，不拼 shell 字符串，不用 `.sh` 包装 npm 命令。

```bash
node tools/checkTimeline.ts
node tools/checkContrast.ts
npm run check
node scripts/render.mjs Main --preset draft
node scripts/render.mjs ThreeDemo --preset draft  # 使用 3D 时确认非黑屏
```

`npm run check` 串联类型、时间轴契约、静态资源引用与对比度检查，任一失败即中断。
交付前检查：无裸色值与禁用动效；正文无溢出且在安全区；间距、字号、时长均用令牌。
抽查均匀分布的静帧和切点，确认无换行错位、素材缺失、首尾硬停；再做整片草稿冒烟。
完整制作步骤见 [制作指南](制作指南.md)，素材和出片参数见 [素材与渲染](素材与渲染.md)。
