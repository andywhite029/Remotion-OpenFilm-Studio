# 动效选型：先问这一个镜头要完成什么

正文与标题统一使用 IBM Plex Sans SC，水印使用公司提供的原图。配色、构图、景别、过渡、节奏、图形语言和配乐由项目决定。技术时间码可保留等宽字体。

## 三个可单独用的镜头

下列页面在原生版和混合版 Studio 的网页素材中可见，可独立裁切、移动，并可覆盖其中的重要文字。每个也可直接在浏览器中打开循环预览。适用范围外可以不用模板，或者只借一个动作。

| 要解决的问题 | 范例 | 改成项目自己的样子 | 什么时候不用 |
|---|---|---|---|
| 让一句结论先站稳 | `editorial.html`：字行依次揭幕、纸面式留白 | 换一句有判断力的标题、重设构图；`data-reveal` 控制各行先后。 | 真实素材或人物已经足够抓人时，可直接硬切入内容。 |
| 让观众跟着证据看到结论 | `data-trace.html`：描线、移动读点、最后给数 | 换真实数据和来源。示例 `data-values` 用 0–100 归一化指数；不同单位或量级要重做刻度。 | 需要精确比较两组数时，静态对比图比动画折线清楚。 |
| 让观众跟上一个具体操作 | `product-focus.html`：先给全局，再局部聚焦和标注 | 先换成真实截图或录屏；调 `transform-origin` 和标注位置，让焦点对准实际动作。 | 已经明显的按钮或画面主体不必再放大。 |

三个页面共享 `motion.js`（便于改节奏）和 `motion.css`（每种布局分段维护，不共享项目色板）。母版中修改以原生项目下的 `motion-kit/` 为准，混合版在构建时同步。做正式镜头时，将整个目录复制为目标项目下的独立目录，例如与 `public/` 同级的 `my-project-motion/`。将副本的页面加入时间轴后，就可以独立调整版式、时间和颜色。

## 开工前写四行

1. **给谁看，看完要记住什么？** 只写一个主目标。
2. **什么素材最能说服人？** 真实画面、现场声、产品录屏、图表，或一条文案。
3. **想让它是什么气质？** 先选构图、色调和节奏，再挑需要的镜头级动作；同一时间只引导一个视觉重点。
4. **哪里应该不动？** 给字幕、数据和关键画面留可读停顿。做一轮去模板复核：如果去掉 Logo 以后仍和上一支片几乎一样，优先改镜头组织和节奏，不是只换配色。
